# 数字经济发展对城乡收入差距的影响研究

> 第九届全国大学生统计建模大赛 - 本科生组
>
> 主题：中国式现代化的统计测度

## 一、 项目简介

数字经济正在深刻改变中国的经济结构和社会格局。本研究基于**2005-2021年中国省级面板数据**，通过构建**数字经济综合评价指标体系**和**城乡收入差距指标体系**，运用**主成分分析、多元回归、空间计量模型、ARIMA预测**等多种方法，系统探究数字经济对城乡收入差距的影响机制。

**核心发现：** 数字经济发展与城乡收入差距呈**显著负相关**，其中**光缆长度、专利申请数、居民人均教育文化娱乐支出**是影响城乡收入差距的关键因素。空间计量分析表明，**东部地区**的影响最为显著。

## 三、研究方法与核心结果

| 方法                  | 用途                           | 核心结果                                               |
| --------------------- | ------------------------------ | ------------------------------------------------------ |
| **主成分分析(PCA)**   | 提取数字经济核心指标、计算权重 | 光缆长度、专利申请数、教育文化娱乐支出权重最高 (0.086) |
| **多元线性回归**      | 分析各指标对城乡收入差距的影响 | 构建了包含14个自变量的回归方程                         |
| **空间计量模型(SDM)** | 分析区域空间效应               | 数字经济在**东部地区**影响最显著                       |
| **ARIMA模型**         | 预测城乡收入差距趋势           | 模型R²=0.99，预测2023-2070年变化趋势                   |
| **灰色预测(GM(1,1))** | 对比验证预测精度               | 与ARIMA对比，ARIMA精度更高                             |
| **LSTM神经网络**      | 多变量时间序列预测             | 捕捉非线性特征，验证模型鲁棒性                         |

## 六、 关键结论

| 结论                   | 说明                                                         |
| :--------------------- | :----------------------------------------------------------- |
| 数字经济与城乡收入差距 | 呈**显著负相关**，数字经济每提升1个单位，城乡收入差距缩小约0.085个单位 |
| 关键影响因素           | 光缆长度、专利申请数、居民人均教育文化娱乐支出、居民人均交通通信支出 |
| 区域差异               | **东部地区**影响最显著，中部和西部地区影响相对较弱           |
| 预测趋势               | 城乡收入差距将持续缩小，但速度逐渐放缓                       |

## 七、项目亮点

##### 1.**多维度指标体系构建**：

从数字基础设施、数字化创新能力、数字产业化、产业数字化4个维度，构建了14个指标的综合评价体系

##### 2.**多方法融合分析**：

主成分分析 + 多元回归 + 空间计量 + 时间序列预测，形成完整的"提取→建模→预测→验证"分析链路

##### 3.**区域异质性分析**：

将中国划分为**四大经济区**（东部、中部、西部、东北），揭示数字经济影响的区域差异

##### 4.**高精度预测**：

ARIMA模型拟合优度 **R²=0.99**，预测结果可靠

##### 5.**政策建议落地**：

基于实证结果，提出**宏观、区域、产业**三个层面的政策建议
