# 数据格式说明

## 一、数据来源
- 国家统计局 (http://www.stats.gov.cn)
- 中国统计年鉴
- 各省份统计年鉴

## 二、数据范围
- 时间跨度：2005-2021年
- 空间范围：中国31个省份

## 三、数字经济指标体系（14个指标）

### 1.数字基础设施
| 指标                 | 单位    | 说明                 |
| -------------------- | ------- | -------------------- |
| 光缆线路长度         | 公里    | 反映网络基础设施水平 |
| 移动电话基站数       | 万个    | 反映移动通信覆盖水平 |
| 互联网宽带接入端口数 | 万个    | 反映宽带接入能力     |
| 互联网上网人数       | 万人    | 反映互联网普及程度   |
| 互联网域名数         | 万个    | 反映互联网应用水平   |
| 网上移动支付水平     | -       | 反映数字金融普及程度 |
| 移动电话普及率       | 部/百人 | 反映移动通信普及程度 |

### 2.数字化创新能力

## 四、城乡收入差距指标体系

### 1.被解释变量
| 指标       | 说明                                            |
| ---------- | ----------------------------------------------- |
| 城乡收入比 | 城镇居民人均可支配收入 / 农村居民人均可支配收入 |

### 2.相对收入差距指标
- 城乡居民人均可支配收入比值
- 基尼系数
- 城乡居民恩格尔系数比值
- 泰尔指数
- 城乡储蓄金额比值
- 城乡居民人均消费支出比值

### 3.绝对收入差距指标
- 城乡居民人均工资收入比值
- 城乡居民人均服务性消费支出比值
- 城乡居民平均每百户年末家用汽车拥有量比值
- 城乡居民人均教育文化娱乐支出比值
- 城乡居民人均生活用品及服务支出比值
- 城乡居民平均每百户年末计算机拥有量比值
