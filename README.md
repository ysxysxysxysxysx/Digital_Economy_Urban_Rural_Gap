# 数字经济发展对城乡收入差距的影响研究

> 第九届全国大学生统计建模大赛 - 本科生组
>
> 主题：中国式现代化的统计测度

## 一、 项目简介

数字经济正在深刻改变中国的经济结构和社会格局。本研究基于**2005-2021年中国省级面板数据**，通过构建**数字经济综合评价指标体系**和**城乡收入差距指标体系**，运用**主成分分析、多元回归、空间计量模型、ARIMA预测**等多种方法，系统探究数字经济对城乡收入差距的影响机制。

**核心发现：** 数字经济发展与城乡收入差距呈**显著负相关**，其中**光缆长度、专利申请数、居民人均教育文化娱乐支出**是影响城乡收入差距的关键因素。空间计量分析表明，**东部地区**的影响最为显著。

## 八、项目难点与优化点

### 1. 高维指标、量纲差异与信息冗余

**难点：** 数字经济由多个维度和大量指标共同刻画，不同指标单位和数量级差异明显，而且指标之间存在相关性，直接建模容易造成信息冗余和多重共线性。

**优化：** 先使用 Min-Max 标准化统一特征尺度，再通过 KMO 与 Bartlett 检验确认数据适合降维，最后使用 PCA 提取主成分，在尽可能保留原始信息的同时压缩特征空间。项目中 KMO=0.882，前两个主成分能够解释大部分信息。

### 2. 关键指标的信息贡献与实际影响方向难以同时解释

**难点：** PCA 可以识别信息贡献较大的指标，但不能直接回答某个指标究竟会扩大还是缩小城乡收入差距。

**优化：** 在 PCA 基础上进一步建立多元线性回归：

```text
Y = β0 + β1X1 + β2X2 + ... + βnXn + ε
```

通过回归系数判断影响方向，通过显著性检验判断影响是否具有统计意义，并结合灵敏度分析观察单个变量变化对结果的影响。

### 3. 传统回归忽略省份之间的空间关联

**难点：** 省级经济数据并非完全独立。数字基础设施、产业、人才、资本和技术可能跨地区流动，因此一个地区的数字经济发展可能对周边地区产生影响。

**优化：** 首先使用 Moran's I 检验空间自相关，再建立空间杜宾模型 SDM：

```text
Y = ρWY + Xβ + WXθ + ε
```

其中 WY 描述周边地区城乡收入差距对本地区的影响，WX 描述周边地区数字经济发展对本地区的影响。模型进一步将影响拆分为直接效应、间接效应（空间溢出）和总效应。

### 4. 全国统一模型容易掩盖区域异质性

**难点：** 东部、中部、西部和东北地区在数字基础设施、产业结构和经济发展水平方面差异明显，数字经济的作用强度不一定相同。

**优化：** 按四大经济区域进行比较分析，研究数字经济影响的区域差异。项目结果显示东部地区影响最为显著，中部次之，西部和东北相对较弱。

### 5. 时间序列存在趋势，不能直接用于预测

**难点：** 2005-2021 年城乡收入差距数据具有时间趋势，非平稳序列直接建模可能导致预测不稳定。

**优化：** 使用 ADF 检验判断平稳性，对非平稳序列进行差分，再建立 ARIMA(p,d,q) 模型，并使用 Ljung-Box 检验残差是否接近白噪声，最后使用 R²、MAE、MSE 评价预测效果。

## 九、核心算法详解

### 1. PCA：解决“数字经济如何量化”

PCA 将多个相关原始变量转换成少数几个彼此不相关的主成分：

```text
Z1 = a11X1 + a12X2 + ... + a1nXn
```

第一主成分保留最大的方差信息，后续主成分依次解释剩余信息。通过主成分载荷和解释方差可以进一步计算指标贡献和综合权重。

项目识别出的关键因素包括：

- 光缆线路长度：反映数字基础设施建设；
- 专利申请数量：反映数字创新能力；
- 居民人均教育文化娱乐支出：反映居民相关消费能力。

### 2. 多元线性回归：解决“哪些因素产生影响”

模型形式：

```text
Y = β0 + β1X1 + β2X2 + ... + βnXn + ε
```

其中 Y 为城乡收入差距，X 为数字经济指标。

- βi > 0：对应指标增加时，城乡收入差距可能扩大；
- βi < 0：对应指标增加时，城乡收入差距可能缩小。

因此回归模型将 PCA 的“信息贡献分析”进一步扩展为“影响方向与程度分析”。

### 3. Moran's I + SDM：解决“影响是否具有空间溢出”

Moran's I 用于判断城乡收入差距是否存在空间聚集：

```text
I > 0：高-高或低-低聚集
I < 0：高-低相邻
I = 0：无明显空间相关
```

确认空间关联后使用 SDM：

```text
Y = ρWY + Xβ + WXθ + ε
```

最终得到：

```text
总效应 = 直接效应 + 间接效应
```

从而不仅研究本地区数字经济的作用，还研究对周边地区产生的空间溢出效应。

### 4. ARIMA：解决“未来如何变化”

ARIMA 由三部分组成：

- AR：利用过去值预测未来；
- I：通过差分将非平稳序列转换为较平稳序列；
- MA：利用历史预测误差修正当前预测。

模型写作：

```text
ARIMA(p, d, q)
```

其中 p 为自回归阶数，d 为差分次数，q 为移动平均阶数。

建模流程：

```text
2005-2021 历史数据
        |
        v
ADF 平稳性检验
        |
        v
必要时进行差分
        |
        v
确定 p、d、q
        |
        v
ARIMA 模型训练
        |
        v
Ljung-Box 残差检验
        |
        v
R² / MAE / MSE 评价
        |
        v
未来趋势预测
```

## 十、算法之间的关系

| 方法         | 核心问题                           | 主要输出                   |
| ------------ | ---------------------------------- | -------------------------- |
| PCA          | 指标太多，如何降维并识别关键信息？ | 主成分、指标权重、关键指标 |
| 多元线性回归 | 哪些指标影响城乡收入差距？         | 回归系数、方向、显著性     |
| Moran's I    | 是否存在空间聚集？                 | 空间自相关程度             |
| SDM          | 周边地区是否会产生影响？           | 直接效应、间接效应、总效应 |
| ARIMA        | 未来收入差距如何变化？             | 时间序列预测结果           |

整体逻辑：

```text
PCA
 |
 | 解决“指标太多”
 v
多元线性回归
 |
 | 解决“影响是什么”
 v
Moran's I + SDM
 |
 | 解决“空间上怎么影响”
 v
ARIMA
 |
 | 解决“未来怎么变化”
 v
最终研究结论
```

## 十一、核心研究结论

1. 数字经济发展水平与城乡收入差距总体呈较显著的负相关关系。
2. PCA 分析中，光缆线路、专利申请和居民人均教育文化娱乐支出属于较关键指标。
3. 数字经济对城乡收入差距的影响具有区域异质性，其中东部地区更加显著。
4. 空间计量模型将数字经济影响进一步拆分为直接效应和空间溢出效应。
5. ARIMA 利用城乡收入差距自身历史规律进行趋势预测，原项目材料的时间序列结论为未来差距仍存在扩大趋势，但增长速度逐渐放缓。

> 注意：回归/SDM 分析的是数字经济变量对城乡收入差距的影响关系，而 ARIMA 主要根据城乡收入差距自身历史序列预测未来趋势，两者属于不同分析层面。

## 十二、项目概括

> **基于 2005-2021 年全国 31 个省份面板数据，通过 PCA 构建数字经济评价体系，利用多元回归识别关键影响因素，引入 SDM 分析区域空间溢出效应，并使用 ARIMA 预测城乡收入差距未来变化趋势。**
